# Agents.md

## Tidewave MCP

If the tidewave mcp server is available and running, then always use Tidewave's
tools for evaluating code, querying the database, etc.

Use `get_docs` to access documentation and the `get_source_location` tool to
find module/function definitions.

Tidewaves docs are available at https://tidewave.hexdocs.pm/llms.txt
